# Engineering Team

Plain-English requirements in; a working, tested Python product out — designed, built,
independently inspected, and revised until it passes or a human says stop.

**Open with "Show a finished run"** to see a real completed build in two seconds: its
actual cost table, its QA report, and the source to download. A live build takes 20–50
minutes and spends real money, so it is gated on this deployment.

See the [repository](https://github.com/) for what measuring this system revealed —
including where the original design turned out to be wrong.
